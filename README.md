# Отчет для собственника

Программа собирает три Excel-отчёта (Estate, Unelma, Nomiqa) из файлов
ОПиУ, БДиР и Прогнозов.

## 📖 Как пользоваться (для конечного пользователя)

1. Открой ссылку на приложение в браузере.
2. Войди по логину и паролю.
3. Выбери **год** и **месяц** отчёта в левой панели.
4. Загрузи файлы через форму:
   - **ОПиУ** — за прошлый и текущий месяц по всем направлениям.
   - **БДиР** — годовые файлы.
   - **Прогнозы** — месячные файлы.
5. Нажми кнопку **«Собрать все отчёты»**.
6. Скачай готовые файлы через кнопки внизу.

**Важно:** файлы загружаются только на время сессии. После закрытия
вкладки они удаляются с сервера.
